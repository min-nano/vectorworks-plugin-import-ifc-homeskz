# MCP サーバのテスト（Claude 側）

（テストの一覧は [`tests/README.md`](../../../tests/README.md#何をテストしているか)）

**`McpServerTests`** … `scripts/mcp/vw-mcp-server.py`（MCP ブリッジの Claude 側）を、
**プラグインと同じ作法でスプールへ応える代役**に対して動かします
（`tests/vw-mcp-server.test.py`）。Vectorworks 側（`src/draw/McpBridge.cpp`）は SDK が要る
ので CI では動かせませんが、**両者の間の約束**（`src/core/Bridge.h` のファイル名の綴り・
原子的な書き方・生存の印）は代役が真似ているので、どちらかを変えればこのテストが失敗します。

確認しているのは MCP のハンドシェイク（`initialize` / `tools/list` / `tools/call`）、**道具の一覧が
代役から取れること**（＝一覧の真実がプラグイン側にあること）、送った順に処理されること、
そして**ブリッジが動いていない／応答が返らないときに待ち切らずに理由を返す**ことです。
**`vw_launch`**（M30）は、起動するもの（`VW_MCP_APP`）を「起動されたら生存の印を書き続ける」
代役に差し替えて、起動して橋が接続されるまで待つこと・一覧の取り直しを促す通知
（`notifications/tools/list_changed`）を出すこと・既に受け付けていれば起動しないこと・
起動するものが無い／橋が接続されないときに理由を返すことを確かめます（Windows の枝＝既定の
インストール先と `tasklist` は CI では走りません）。**一覧が古いまま**（アプリを Vectorworks
より先に起動した。実機で起きた）の場面も押さえていて、`vw_bridge_status` がプラグインの
道具を並べること・取り直しを 1 度だけ促すこと・`vw_call` で道具に届くことを確認します。
M38 で 3 つ追加しました——**`vw_restart` のあと、橋が一度切断されて再び接続されるのを見届ける**
こと（代役は応答を書いてから印を消してしばらく応答しない）、**長く走る道具の最中（`busy_until`）は
印が古くても生きていると判定する**こと（`vw_run_test` の 1 周は 1 分以上印を書き直せない）、
**プラグインの表の待ち時間（`timeoutSeconds`）を Claude へ見せない**こと。既定のプラグイン名
（開発版）でスプールを探し当てることも押さえます。M40 で **`vw_run_test` は橋が居なければ
Vectorworks を起動してから要求する**こと（`check_launch_on_demand`。代役は印を書くだけでなく
`vw_tools` と `vw_run_test` に応える・引数がそのまま届く・起動したことを返す・読む道具では
起動しない）を追加しました。殻が頼まれた更新・再起動を済ませる側
（`src/Extensions/ExtMcpPalette.cpp`）は SDK が要るので CI では動かせず、その判断は
`RemoteDevUpdateWith`（`UpdaterFlowTests`）で押さえてあります。
python3 だけで走り、ネットワークも SDK も要りません。

加えて **スプールの探し方**（`check_spool_search`）を直接確認しています。実機で失敗したのが
まさにここで、Claude のデスクトップアプリが `$TMPDIR` を渡さないため候補が `/tmp` だけに
なり、Vectorworks が利用者ごとの一時フォルダへ置いた橋を見つけられませんでした
（[M24「探し方は実機で外した」](../../dev-notes/milestones/m24-mcp-bridge.md#探し方は実機で外したtmpdir-が来ない)）。macOS では
利用者ごとの一時ディレクトリを取得できること・`$TMPDIR` が無くてもそれが候補に入ること・
**`/tmp` を候補にしないこと**（同「当てずっぽうの候補は置かない」）を、それ以外の OS では
その枝が走らないことを確かめます。**持ち主と権限の確認**（他から書けるスプールを
使わない）も、ここで押さえてあります。

**macOS の枝は CI では走りません**（このテストを回すのは Linux のランナーだけ）。
実機で `vw_bridge_status` の「探した場所」を目で確かめるところまでが 1 組です。
