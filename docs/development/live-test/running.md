# ローカルセッションでの回し方

```
   ① Claude: 直して push → scripts/ci-wait.sh で dev ビルドを待つ
        ↓
   ② Claude: vw_update（同じブランチの新しいビルドを入れて本体を読み直す）
         restart_required なら、人に断ってから vw_restart（保存の確認が出ることがある）
        ↓
   ③ Claude: vw_run_test に ifc と template（と、変えたい設定があれば settings）を渡す
         （ifc は tests/fixtures/ の IFC、template は tests/fixtures/Default.sta。どちらも
          絶対パス。前の周の図面を保存せずに閉じ、テンプレートから開いた新しい図面へ、
          図面にあるもので組んだ既定の設定を settings で上書きして取り込み、描き上がりを
          一時ファイルへ保存して報告を返す。Vectorworks が起動していなければ起動してから）
        ↓
   ④ Claude: 報告と vw_log を読み、前の周の報告と比べ、人に絵で確かめてほしい点を返す → ① へ
```

- **Vectorworks を使えるのは 1 度に 1 つのセッションだけです**（M42）。別のセッションが
  使用中なら操作は断られるので、`vw_lock_status` に `wait` を渡して空くのを待ちます（相手の
  周を人に確かめずに上書きしない）。
- **次の実行まで状態を持ち越さないなら、`vw_lock_release` で片付けて解放します**（M42）。
  実機テストの図面を保存せずに閉じ、一時ファイル（各周の図面）・記録・報告を消してから
  空けます。① の CI の往復を待って続けるなら解放しません（最後の操作から 60 分は占有が
  続きます。それを過ぎて解かれたときや、セッションを閉じたときは自動で片付きます）。
- **条件は毎周渡します（M43）。** プラグインは前の周の条件を覚えていません。`ifc` か
  `template` が無いと、何もせずにそう返します。同じ条件で回し続けるなら、同じ `ifc` /
  `template` / `settings` を毎回渡します。
- **設定は、テンプレートから開いた図面にあるもので組んだ既定に、`settings` で上書きします**
  （`draw::presetImportSettings` → `core::applyTestSettings`）。既定は設定ダイアログを
  まだ一度も決めていないときの初期値と同じで——既定名のシンボルが図面にある役割だけ取り込み、
  図面枠は最初のスタイル、寸法規格は JIS（無ければ最初）、伏図のまとめ方・外す通り・垂木は
  既定。`settings` に書けるのは設定ダイアログで決められるものすべてです:

  ```json
  {
    "symbols": {"床束": "床束（特注）", "火打": false, "継手": true},
    "title_block": "図面枠 A3",
    "dimension": "JIS",
    "merge_levels": ["1:3531"],
    "skip_sections": ["X1"],
    "rafter": {"width": 45, "height": 90}
  }
  ```

  `symbols` の鍵は役割の表示名（設定ダイアログの行の名前）で、値はシンボル名（そのシンボルで
  取り込む）・`true`（既定のシンボルで取り込む）・`false` か空文字列（取り込まない）。
  `title_block` / `dimension` の空文字列は「置かない／入れない」。`merge_levels` は
  `"<階の番号>:<高さ mm>"`。**読めない項目があれば、何も描かずに理由を返します**（頼んだ
  条件と違う条件で黙って走らせない）。
- **前の周と比べるのはセッションの仕事です。** 報告は 1 周ぶんで完結しており、前の周からの
  差分は載りません（M43）。
- **再起動しても保存の確認はふつう出ません**（M39）。実機テストの図面は周の終わりに一時
  ファイルへ保存してあるからです。出たら、人が保存していない図面を開いているということ
  なので、その応答は人に任せます。
- **ダイアログは 1 枚も出しません。** 失敗も応答の文言で返します。
- **人が手で確かめたいときは、本番の「IFC (ホームズ君) 取り込み…」を使ってもらいます。**
  その診断ログも `vw_log` で読めます（実機テストのメニューは M43 で削除した）。
