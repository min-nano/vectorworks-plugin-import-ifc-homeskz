# 図面の用意（M39）

**どの周も、テンプレートから開いた新しい図面へ描画します。**

1. **テンプレートを確かめます。** `vw_run_test` に渡された `template`（`.sta`）をそのまま
   使います（`CheckTemplate`。M43 から複製しない。`.sta` を開いてもファイルそのものは
   変わらない）。
2. **周の頭で、自分で保存した図面のうち開いているものを保存せずに閉じます**
   （`CloseOwnedDocuments`）。
3. **テンプレートを `OpenDocumentPath` で開きます。** `.sta` を渡すと**そのファイル自体では
   なく、中身を複製した無題の新規文書**が開く（[Findings「Documents」](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Documents.md)）
   ので、テンプレートには前の周の描画結果が 1 つも書き戻りません。
4. 取り込みます。
5. **描画結果を一時ファイル（`round-N.vwx`）へ保存し、自分の図面として記録します**
   （`SaveRoundDocument`。取り込みが失敗・中止した周も）。未保存の変更が残らないので、
   Vectorworks を再起動しても保存の確認が出ません。次の周の 2 で閉じます。

M38 までの「取り消し」→「作業ファイルを開き直す」→「前の周が作ったレイヤを消す」の
3 段構えは**やめました**（利用者の指示）。取り消しは取り消しスタックの中身に、レイヤ削除は
「取り込み前から在ったレイヤへ描いた分は残る」に左右され、どちらも「戻ったかどうか」を
周ごとに疑う必要がありました。
