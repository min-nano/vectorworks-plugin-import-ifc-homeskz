# 文書とコメントの書き方

ソースのコメント・Markdown・コミットメッセージ・PR 本文に共通する書き方です。全変更に
共通する要点は [`CLAUDE.md`](../../CLAUDE.md)「コメント・言語」にあり、このページはその細則と
用語の対応表です。

## コメントの並べ方

関数・型・モジュール（ファイル冒頭）のコメントは、**設計と実装に要る順に**書きます。

1. **何をするものか**（目的・入出力・責務の範囲）。
2. **注意事項**（守るべき前提・呼び出し側の義務・副作用・やってはいけないこと）。
3. **注意事項の理由や補足**（根拠・実測の結果・経緯・マイルストーン番号・参照先）。

経緯（「以前は…していたが…」）や調査の結果は 3 に置き、1 の前に出しません。読み手がまず
知りたいのは「これは何か」と「何に気を付けるか」で、なぜそうなったかはその後で足ります。

```cpp
// 横架材 1 本を構造材 PIO として配置し、断面寸法を設定する。
// 断面寸法は書き込んだ後に読み出して確認し、反映されなかった本数を返す。
// 理由: パラメータの universal 名が 1 文字でも違うと、setter は失敗を返さずに値を
// 無視する（M6 の垂木で発生。SDK リファレンス Findings「Parametric Objects」）。
```

行内の短いコメント（1 行で済むもの）は、この順序に当てはめなくて構いません。

## 用語

**くだけた言い回し・比喩・俗語を使わず、技術文書の語で書きます。** 同じものを指す語は
1 つに揃え、表記揺れを作りません。

### 言い換える語

置き換え先は文脈で選びます（「作り直す」が PIO の再計算なのかパスの再生成なのか等）。

| 避ける | 使う |
| --- | --- |
| 絵・絵を描く・描く | 描画する・描画結果・図形・表示（「描かれる」→「描画される」） |
| 作り直す・作り直し | 再生成する・再描画する・再計算する（PIO のリセット）・再構築する |
| 〜を見る・見ない（判定の対象） | 確認する・参照する・考慮する／参照しない・判定に使わない |
| 中止を見る・中止は見ない | 中止要求を確認する／中止要求はこの処理に割り込めない |
| 拾う・拾える | 取得する・検出する・抽出する |
| 潰れる・潰れ | 退化する（長さ 0 になる）・区別されなくなる（情報が失われる） |
| 持ち帰る | 記録する・出力する（「診断ログへ持ち帰る」→「診断ログへ記録する」） |
| 引き比べる | 照合する・比較する |
| 手繰る | 追跡する・特定する |
| 叩く | 呼び出す・アクセスする・要求を送る |
| 跨がせる（境界を） | （境界を越えて）受け渡す |
| 降ろす（本体を） | アンロードする |
| 読み直す（本体を） | 再読み込みする |
| 化ける | 文字化けする |
| 効かない | 反映されない・機能しない |
| 繕う | 修復する・補正する |
| 逃げ道 | 代替手段・回避策 |
| 撒く | 分散させる・各所に書く |
| 噛ませる | 挟む・間に置く |
| 掴む・握る | 取得する・保持する |
| 食う | 消費する |
| 足す | 追加する |
| 外す | 削除する・除外する・無効にする |
| 素の | 未加工の・生の・そのままの |
| 足場 | 補助の仕組み |
| 肝 | 要点 |
| 当たる（上限に） | 上限に達する |
| 写す | 複製する・コピーする |

### そのまま使う語（定義済みの用語）

次は本リポジトリで意味を定めて使っている語なので、言い換えません。

| 語 | 意味 |
| --- | --- |
| 殻 | VectorWorks が起動時に読み込むプラグイン本体のモジュール（`.vwlibrary` / `.vlb`） |
| 本体 | 殻が読み込む、実処理を持つモジュール（`.vwpayload`） |
| 命令・命令セット | 解析フェーズの出力（`core::Document` とその構造体） |
| 周 | 実機テストの 1 回の実行（取り込み → 報告） |
| 実機・実機テスト・実機確認 | ローカルの VectorWorks での実行と、その結果の確認 |
| 読み戻し | 書き込んだ値を読み出して確認すること |
| 検算 | 開発ビルドだけで行う読み戻しと照合（`#if VW_DRAW_VERIFY`） |

建築・構造の用語（伏図・軸組図・横架材・通し柱など）と、SDK の API 名・用語はそのまま使います。

## 変えないもの

- **見出し（Markdown の節の名前・ページの題名）は変えません。** コメントや PR から
  `docs/DEVELOPMENT.md「<節の名前>」` の形で参照されています。変える場合は参照元をすべて
  直します。
- **文字列リテラル（画面に出る文言・ログの文言）は、このページの対象外です。** 変えると
  動作とテストが変わります。
- 英語で書かれたコメント（スクリプトの一部）は英語のまま保ちます。
