# 使い方

（利用者向けのページの一覧は [`README.md`](../../README.md#使い方とドキュメント)）

## 1. 図面側で用意しておくもの

プラグインは**既存のリソースを作りも書き換えもしません**（唯一の例外は耐力壁の伏図記号の
シンボルで、耐力壁を取り込むときに図面に無ければ作ります。[「既知の制限」](known-limitations.md)）。
次のリソースは取り込み先の図面（またはテンプレート）に用意しておいてください。**無くても
取り込みは進みます**が、その要素は置かれない（シンボル）か、既定の属性で描画されます
（スタイル）。何が足りなかったかは診断ログに名前で出ます（完了ダイアログの
「ログを表示」。下記「5. 困ったときは」）。

| 種別 | 名前 | 無いとどうなるか |
| --- | --- | --- |
| シンボル定義 | `アンカーボルト_M12` / `アンカーボルト_M16` / `床束` / `鋼製火打` / `仕口` / `継手` | そのシンボルが置かれない |
| シンボル定義 | `柱伏図記号` / `束伏図記号` | 伏図記号が描画されない（断面記号は描画される） |
| 図面枠スタイル（任意） | 図面で使っているもの（名前は自由） | 図面枠が置かれない（選択肢にも出ない） |
| 文字スタイル | `寸法(6pt)`（任意） | データタグの文字は大きさ（6pt）だけを与えて描画される |
| 文字スタイル | `図面ラベル(10pt)`（任意） | 軸組図の図面ラベルの文字は大きさ（10pt）だけを与えて描画される |

**シンボルは名前が違っていても構いません。** 上の名前は**既定**で、取り込みのたびに出る
設定ダイアログで、図面にある別のシンボルへ割り当て直せます。**その要素を取り込まない**
という選び方もできます（下記「2. 実行する」）。

**図面枠は図面にあるスタイルを当てるだけ**で、プラグインはスタイルを作りません。図面枠
スタイルが 1 つも無い図面では、設定ダイアログのその行が選べない状態で開きます。

断面寸法の**データタグ**とグラフィック凡例は、**スタイルを使わずに**——図面にスタイルを
作らず、既存のスタイルも当てずに——置かれます。中身（タグの寸法・凡例の並び）は
オブジェクトそのものが持つので、取り込みのたびに名前付きリソースが増えることはありません。
凡例のイメージの縮率は 1:50 のままです（[「既知の制限」](known-limitations.md)）。

横架材のデータタグには、断面寸法の後ろに**その階の FL（最上階は軒高）から測った天端の
高さ**を添えます（`105×240 (2FL -872)`。傾斜のある材は `(2FL -872~-40)`）。添えるのは階の
標準の高さと違う横架材だけで、隅木・谷木には添えません。高さは**材の高さに連動**し、
あとで材を上下に動かしたり傾けたりすれば注記の数値も追随します（正の値は `+`、1,000 以上は
3 桁ごとにコンマ）。

## 2. 実行する

1. **IFC (ホームズ君) 取り込み…** を実行します
   （コマンドが見当たらないときは、[「インストール」](install.md)の最後の手順でワークスペースへ
   追加してください）。
2. IFC ファイルを選びます。
3. **設定ダイアログ**で、取り込む要素と配置するシンボル、**図面枠のスタイル**、
   **寸法規格**、**垂木の断面**を選びます。
   - 要素（アンカーボルト 2 種・床束・火打・仕口・伏図記号 2 種・継手）ごとに 1 行あり、
     **チェック（取り込むか）／シンボルの選択**が並びます。選択は Vectorworks 純正の
     **サムネイル付きポップアップ**なので、名前が紛らわしくても画像で確かめられます。候補は
     **いま開いている図面にあるシンボル**だけで、プラグインオブジェクトのスタイル
     （データタグ・図面ラベル・グラフィック凡例など）は並びません。
   - **シンボルの行の下は「図面枠スタイル」**です。ここにチェックを入れてスタイルを選ぶと、
     伏図・軸組図の**すべてのシートレイヤ**に図面枠が 1 つずつ置かれます。候補は図面にある
     **図面枠スタイル**だけです。図面に図面枠スタイルがあれば**チェックあり**で、一覧の
     最初のスタイルが選ばれています（2 回目からは前回の選択。図面枠が要らなければ
     チェックを外してください）。
   - **その下の行は「寸法規格」**です。チェックを入れて寸法規格（JIS など、図面にあるもの）を
     選ぶと、伏図・軸組図へ寸法が（軸組図にはレベル基準線も）入ります。この行だけは名前の
     プルダウンです。**既定はチェックあり**で、「JIS」があればそれ、無ければ一覧の最初の
     寸法規格が選ばれています（2 回目からは前回の選択。寸法が要らなければチェックを外して
     ください）。
   - 寸法規格の下の **「垂木の断面（幅×せい mm）」** に、垂木の幅とせいを mm で入れます
     （ホームズ君の IFC には垂木の寸法が出てこないため）。**すべての垂木に同じ断面**が
     使われ、野地板もそのせいの分だけ上に載ります。**既定は 45×45**（2 回目からは前回の値）。
     全角の数字でも入れられます。読めない値（空・文字・0 以下・1000 を超える値）の欄は
     前回の値のまま取り込み、その旨がログに残ります。
   - IFC の 1 つの階に**横架材の高さが複数ある**とき（スキップフロア）は、いちばん下に
     **伏図のまとめ方**の欄が出ます。伏図は横架材の高さごとに 1 枚作るのが基本で、
     「2階床伏図: FL-40 を FL-872 と同じ伏図にまとめる」のような行（高さはその階の FL、
     最上階は軒高から測ります）にチェックを入れた
     高さだけが、同じ階の 1 つ低い高さと同じ伏図にまとまります（**既定はまとめない**）。
     高さが 1mm でも違えば別の高さとして並ぶので、まとめるかどうかは設計者が決めてください。
     同じ階の高さが 1 つだけの建物では、この欄は出ません。
   - シンボルの行の初期値は「1. 図面側で用意しておくもの」の表の既定名（2 回目からは前回
     選んだもの）です。そのままでよければ **取り込む**を押してください。
   - **その名前のシンボルが図面に無い行は、チェックが外れた状態で開きます**（勝手に別の
     シンボルへ差し替わることはありません）。使わない要素も、チェックを外せば取り込まれません。
   - 選んだ内容は**図面には保存されません**（Vectorworks を終了するまで覚えています）。
4. **軸組図にする通り**を選ぶダイアログが出ます。軸組図が描画される通りが X通り・Y通りに
   分けて**すべてチェックの入った状態**で並ぶので、要らない通りのチェックを外して
   **取り込む**を押してください。チェックを外した通りの軸組図は描画されません（シート
   レイヤの割り付けも残った軸組図だけで決まります）。この選択は覚えず、毎回すべて
   チェックの入った状態で開きます。軸組図にする通りが 1 本も無い IFC では出ません。
5. 進捗ダイアログに「いま何を・何件中の何件まで描画したか」が出ます。**キャンセル**で
   途中中断でき、そこまでに描画したオブジェクトは図面に残ります。
6. 完了ダイアログに、**どのファイルを取り込んだか・成功したか・問題があったか**が出ます。

完了ダイアログの読み方:

- **1 行目が結果**です。「取り込みが完了しました」なら、命令をすべて描画できて異常もありません。
  「うまくいかなかったところがあります」なら、描画できなかった要素があるか、描画側で異常が
  出ています。
- **何がどれだけ描画できたか（要素ごとの内訳）・所要時間・その原因はログにあります。**
  ダイアログの「ログを表示」を開くとその場で読めます（下記「5. 困ったときは」）。
- `※` で始まる行は、**その場で操作が要ること**です（伏図・軸組図の「更新」と、
  「取り消し」が**通常の方法では機能しないとき**の断り）。

## 3. 取り消す

取り込み直後の **「取り消し」1 回**で、取り込みが作ったレイヤごと元の状態に戻ります
（編集メニューが「取り消し: ホームズ君 IFC 取り込み」と読めます）。

ただし次は戻りません（**戻らないとき・一部しか戻らないときだけ**、完了ダイアログが
その旨を伝えます。1 回で戻せるときは何も出ません）。

- **クラス・ストーリ・レベルテンプレート**（リソースなので残ります。図面の見た目は
  取り込み前に戻ります）。
- **取り込み前から在ったレイヤへ描画した分**（同じ図面への 2 回目の取り込みなど）。その
  レイヤごと消すわけにいかないためです。

## 4. うまくいかないとき

- 壊れた IFC・途中で切れた IFC を読ませても Vectorworks は落ちません。読めない文は
  読み飛ばして読めたところまでを取り込み、結果はいつもの完了ダイアログに出ます（何も
  読めなければ「取り込める要素が見つかりませんでした」）。
- 取り込みの途中で予期しないエラーが起きたときは、エラーダイアログが 1 通だけ出ます。
  本文に「詳細:」の行があり、**どこまで進んでいたか**はログの最終行で分かります。

## 5. 困ったときは（ログをコピーして貼る）

**取り込みのたびに診断ログが書かれます。** 完了ダイアログ（エラーダイアログも同じ）の
**「ログを表示」を開くと、その全文がその場で読めます**——スクロールでき、選択してコピー
できるので、**不具合の報告や改善の依頼にはここをコピーして貼ってください**。ふだんは畳んで
あるので、うまくいっているときに読む必要はありません。

ログに入るのは次のものです。

| 何が | 何のために |
| --- | --- |
| ビルド（プラグイン名・stable / dev・コミット・ブランチ）と実行環境 | どのリビジョンで起きたのかを取り違えないため |
| 日時と、対象にした IFC のフルパス・大きさ、このログ自身の場所 | いつ・どのファイルの話かを突き合わせるため |
| 取り込みの設定（配置するシンボル・図面枠・寸法規格・伏図のまとめ方・軸組図から除外した通り・垂木の断面） | どの設定で取り込んだか（「シンボルが置かれない」などは、まずここを確認する） |
| 解析・描画のフェーズが 1 行ずつ（開始からの経過ミリ秒つき） | 何を処理したか・どこで時間を使ったか・**どこで止まったか** |
| 結果（成功／問題あり／中断・所要時間・要素ごとの内訳・注意・記録・取り消しの効き方） | 何がどれだけ描画できて、何がうまくいかなかったか |

ファイルとしては一時ディレクトリの `min-nano_structure.log` に書かれます。**場所はログの
見出し（「ログ:」の行）に書いてあります**——完了ダイアログには出しません（場所を知りたいのは
ログを見ようとしたときだけで、そのときログはもう目の前にあるからです）。何かの事情で
ファイルへ書けなかったときも、その旨が見出しに出ます（ログ欄の内容をコピーしてください）。
**取り込みのたびに書き直され、直前の 1 回ぶんだけが残ります。** 出力先を変えたいときは、
環境変数 `HOMESKZ_IFC_TRACE` にパスを入れてください。

1 行ごとにフラッシュして書くので、無言で落ちた場合でも**最終行の直後**が原因箇所です。
