# 既知の制限

（利用者向けのページの一覧は [`README.md`](../../README.md#使い方とドキュメント)）

- **ホームズ君構造EX が出力する IFC 専用**です。汎用の IFC には対応しません（既知の
  サブセット前提で最小の STEP リーダを組んでいます）。
- **ホームズ君側で梁せい計算・基礎構造計算を済ませてから IFC を出力してください。**
  未計算のまま出力すると部材の寸法が正しく出ないことがある、とホームズ君の説明にあります
  （プラグインからは計算済みかどうかを判別できません）。許容応力度計算が済んでいれば、
  部材の仕様・寸法はその結果で出力されます。
- **床下地・野地板の厚さは IFC の値を使いません。** ホームズ君は床下地材 28mm・屋根版 180mm
  の固定値で出力するため、床下地 24mm・野地板 12mm の既定値で描きます。
- **床版の開口（階段の吹抜けなど）は塞がった形**で入ります。外形だけを読んでいます。
- **ストーリやレベルがすでに入っている図面へ取り込むと、一部の階が描けません。**
  既存のストーリとぶつかってストーリを作りきれず、その階の柱・梁・耐力壁などが
  「配置先レイヤが無い」として置かれません。新しい図面（またはストーリの無い
  テンプレート）へ取り込んでください。
- **配筋は未対応**です（レコード `配筋` は設定しません。[「残っている宿題」](../dev-notes/open-issues.md)）。
- **ロフトの床は床梁から合成した近似**です（ホームズ君がロフトの床版を出力しないため）。
  床梁で囲まれた吹抜けは塞がり、骨組みが閉じていない部分は床になりません。
- **地中梁は「底盤を削り取るモディファイア」と「可視ソリッド」の 2 つ**で表現しています。
  スラブへ「足す」噛み合わせは、専用 API が実機で失敗するため使えません
  （[SDK リファレンス「Slabs and Extrudes」](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Slabs%20and%20Extrudes.md)）。
- **地中梁の下の床付け（捨てコン・砕石）も押し出しソリッド**です。VW スラブの構成層は
  一様な厚みの水平な層しか表せず、地中梁の下で深さが変わる床付け・傾斜部の法線方向の
  厚みを表現できないためです（[開発メモ「基礎の床付け」](../dev-notes/milestones/m17-footing-bedding.md)）。
  厚みは砕石 100mm ＋ 捨てコン 30mm の既定値で、IFC からは読みません。
- **取り込み直後の伏図・軸組図は、1 回「更新」するまで床・野地板が柱・梁を覆って見えます。**
  VW はデザインレイヤを**高さの降順**（上にあるものが前面）で描くため、床仕上げ天端が
  構造天端より上にある以上、そのままでは床が手前に来ます。プラグインは伏図向けの重ね順
  （床・野地板を背面へ）を図面へ入れていますが、**それが絵に反映されるのは更新のとき**です。
  ビューポートを 1 回更新するか、ファイルを開き直すと正しく描き直されます
  （[SDK リファレンス「Layers and Stories」](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Layers%20and%20Stories.md)）。
- **グラフィック凡例のイメージの縮率は 1:50 のまま**です。伏図の縮尺は用紙への収まりから
  自動で決まる（1:75 など）ので、凡例のシンボルだけが図と違う大きさで並ぶことがあります。
  合わせたいときは、凡例を選んでオブジェクト情報パレットの**「イメージの縮率」**を伏図の
  縮尺（取り込みの記録に出ます）へ変えてください——**手で変えれば枠も中身も正しく変わります**。
  プラグインからは変えられません
  （[SDK リファレンス「Graphic Legends」](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Graphic%20Legends.md)）。
- **図面枠は用紙の中心に置くだけ**です（枠の中身はスタイル任せ）。図面枠が図番・図面タイトル・縮尺などを自分で
  書く場合、その中身は図面枠スタイル側の設定（シートレイヤの情報を引く欄）に従います。
  プラグインは図面枠の中身を書き換えません。また**伏図では図面枠の枠線・表題欄と
  ビューポートが重なることがあります**——伏図の縮尺と位置は用紙の印刷可能領域から決めていて、
  図面枠が占める分は差し引いていないためです。軸組図は図面枠を仮に置いて測り、枠の内側
  （枠線の無い表題欄だけのスタイルなら、その高さを用紙の下から空けた残り）へ並べますが、
  枠線のある図面枠では表題欄の位置までは測れないので、上へ寄せて余りを下へ回します。
- **柱記号と耐力壁は柱を動かした瞬間には追随しません。** リセット・ファイルの再オープン・
  書き出し／印刷の直前に描き直されます（VW に「他の図形が変わったら再計算する」仕組みが
  ないため）。耐力壁はそのとき両端の柱を探し直して軸組内法を引き直すので、**更新すれば
  柱の移動に合わせて伸縮します**（探すのは耐力壁の端から 300mm ほどの範囲で、それより
  遠くへ動かした柱には付いて行きません）。
- **耐力壁は伏図では記号だけ**（筋かい＝直角三角形・面材＝壁に平行な線と丸）です。面や
  筋かいの形は軸組材と重なって図が読めなくなるため、伏図には描きません（形は軸組図に
  出ます）。記号は**その階の伏図**に出ます（1 階の耐力壁は 1 階床＝土台伏図）。壁芯には
  土台・胴差が載っていて記号が隠れるので、記号は壁芯から離した線の上に置きます
  （面材ならその面材のある側）。記号の大きさは**紙の上で三角 6×3mm・丸 直径 3mm**に
  固定で、伏図の縮尺が変わっても変わりません（縮尺非追従）。壁芯からの離れ（既定 200mm）は
  オブジェクト情報パレットの「伏図記号の離れ」で変えられます。

  記号の絵は**シンボル**（`耐力壁記号_筋かい` / `耐力壁記号_面材`）で、耐力壁がある図面
  にだけ作られます。**このプラグインが図面へ作る唯一の名前付きリソース**で、シンボルを
  編集すればすべての耐力壁の記号を一括で差し替えられます（同じ名前の定義が既にあれば
  作り直しません）。縮尺非追従のために、伏図に映るデザインレイヤ（`n-耐力壁` を含む）の
  縮尺は伏図の縮尺に揃えられます。
  筋かいの三角は**斜辺の傾きが材の向き**（足元→頂部）を表し、たすき掛けは三角を反転して
  重ねた形になります。
- **耐力壁の上端は左右で変えられます。** 取り込みは上端を水平に置きますが、登り梁の下に
  取り付く耐力壁のように左右で高さが違うときは、オブジェクト情報パレットの
  「内法上端（始点）」「内法上端（終点）」を書き換えてください。値は内法の両端（柱の
  内側面）での高さで、間は直線で結ばれます（軸組図の面材は台形に、筋かいは台形の対角線に
  沿った帯になります）。「内法上端（終点）」を「内法下端」以下にすると、始点側と同じ高さ
  （水平）として扱います。
- **軸組図では筋かいも面材も壁芯の面に描かれます。** 軸組図は通り芯（＝壁芯）で切った
  断面で、切断面より奥は表示しないため、面材を実物の板の位置（壁芯から 58.5mm ほど外）に
  描くと図から消えてしまうためです。両面に張った面材は 2 枚が同じ位置に重なります。
- **面材の「表・裏」に内外の意味はありません。** IFC に内外の区別が無いので、軸の向き
  （始点→終点の左手側が表）で機械的に決めています。両面に張った面材を**ハッチングの向きで
  見分ける**ためのものです。ハッチングそのものはクラス（`04構造-02木造-06耐力面材-01壁-01表`
  / `-02裏`）の属性なので、図面テンプレート側で決めてください。
- 断面ビューポート（軸組図）の範囲は、奥行きだけが無限で、**高さと長さは建物を包む実寸
  ＋余白**です（SDK に「無限」を指定する手段がありません。実用上は同じ見え方になります）。
