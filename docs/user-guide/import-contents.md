# 取り込むもの

（利用者向けのページの一覧は [`README.md`](../../README.md#使い方とドキュメント)）

| IFC 側 | 図面にできるもの | 配置先レイヤ |
| --- | --- | --- |
| `IfcBuildingStorey`（`…FL`） | ストーリ・ストーリレベル・デザインレイヤ | — |
| `IfcGridAxis` | 通り芯（`GridAxis`。軸名ラベル・基点バブル付き） | `共通` |
| 基礎梁（`IfcFooting`） | 立上り＝**壁**（人通口で分割／切り下げ、交点は壁結合、端部のキャップ） | `F-立上り` |
| 底盤（`IfcSlab` / `IfcFooting`） | 底盤＝**スラブ**（コンクリート＋砕石の 2 層）。地中梁の位置は削り取り、同じ形の可視ソリッドで埋める。地中梁の下には床付け（捨てコン＋砕石。傾斜部は砕石のみ、外周部は 50mm 張り出す）を敷く | `F-底盤` |
| 床版（`IfcSlab`） | 床＝**スラブ**（床仕上げ＋床下地）。スキップフロアの段差は絶対 Z で表現 | `n-FL` |
| （床梁から合成） | ロフト（小屋裏収納）の床。ホームズ君は床版を出力しないので床梁が囲む領域から合成 | `R-FL` |
| `IfcBeam` / `IfcMember` | 横架材＝**構造材ツール**（土台・梁・桁／母屋・棟木／登り梁）。取り合いの端点は相手の芯線に置き、材の範囲は端部オフセットで戻す（下記）。登り梁は屋根面へスナップ | `n-横架材天端`・`n-軒桁`・`n-母屋`・`{from}to{to}-登り梁`（映す伏図の範囲。柱と同じ） |
| `IfcColumn` | 柱・小屋束＝**構造材ツール**。またぐレベルで span レイヤに分割。上端は受ける横架材の天端に置き、梁せいは端部オフセットで戻す（下記）。柱頭・柱脚金物の型名を構造材 ID に含む | `{from}to{to}-柱` |
| 屋根版（`IfcSlab`） | 垂木＝**構造材ツール**（断面は設定ダイアログで一律に指定。既定 45×45。＠455 以下）と野地板＝**屋根面オブジェクト**（12mm） | `n-垂木`・`n-野地板` |
| `IfcMechanicalFastener` | アンカーボルト（M12／M16）のシンボル | `F-アンカーボルト` |
| （大引から算出） | 床束のシンボル（910mm 間隔。立上りと重なるものは置かない） | `F-床束` |
| `火打:…` | 火打のシンボル（内角の二等分方向へ回転） | 横架材と同じレイヤ |
| （横架材・柱から導出） | 仕口のシンボル（受ける材のある端部。高さは横架材の天端に合わせる） | 横架材と同じレイヤ |
| （横架材から導出） | 継手のシンボル（同一直線上で横架材どうしが突き付く箇所に 1 つ。シンボルの +X を女木へ向ける——土台は M12 アンカーボルトの反対側、梁・大引・母屋は支点（下階の柱・小屋束・床束）の側。支点の間隔が短い継手は、ほかの継手の支点からの距離に合う側。高さは横架材の天端に合わせる） | 横架材と同じレイヤ |
| （柱から導出） | 柱・小屋束の**断面記号**（柱＝×／小屋束＝／）と**伏図記号** | span レイヤ・`{to}-柱伏図記号` |
| `筋かい:…`（`IfcMember`）・`面材:…`（`IfcWall`） | 耐力壁＝**専用のプラグインオブジェクト**（両端が柱に紐付き、柱を動かすと内法が引き直される）。伏図は記号だけ（筋かい＝向きを表す直角三角形・面材＝壁に平行な線と丸。横架材と重ならないよう壁芯から離して描画する）、軸組図は形状（筋かいは実幅の帯・面材は軸組内法を埋める面。表と裏はハッチングの向きで区別） | `n-耐力壁` |
| — | **伏図**（基礎伏図・柱梁伏図・屋根版のある階の母屋伏図）。柱梁伏図は**横架材の高さごとに 1 枚**（スキップフロアで 1 つの階に高さが複数あれば、それぞれの高さの梁伏図。設定ダイアログで同じ伏図にまとめられる）。切断レベルで表示レイヤを絞り、断面寸法データタグとグラフィック凡例を載せる | シートレイヤ `1`, `2`, … |
| — | **軸組図**（柱と梁が通る通りごとの断面ビューポート）。断面寸法データタグ付きで、各図の真下の中央に**図面ラベル**（図面タイトルだけ。文字スタイル「図面ラベル(10pt)」が図面にあれば使う）を置く。1 枚の用紙に上下 2 段で並べ、収まらなければシートレイヤを追加する | シートレイヤ（伏図の続き番号） |

## できあがる図面の構造

- **デザインレイヤ** … 階の接頭辞（最下階から `1`, `2`, …／最上階は `R`）＋レベル名で
  `1-FL` / `1-横架材天端` / `R-軒高` / `R-垂木` / `1-耐力壁` のように作られます。柱は
  `1to2-柱` のように**またぐレベル**でレイヤが分かれ、通り芯は `共通`、基礎は `F-…` です。
  1 つの階に横架材の高さが複数あるとき（スキップフロア）は、標準の高さ（その階の横架材天端・
  最上階は軒高）以外の横架材・床・耐力壁が `2-横架材天端(FL-872)` のように**高さを添えた
  レイヤ**へ分かれ、柱のレイヤの番号は階ではなく**伏図の単位**（下から数えた横架材の高さの
  順）になります。
  レイヤの重ね順は「伏図で床・野地板が柱・梁を覆わない」ように並べ替えられます。
- **クラス** … 部材は `04構造-02木造-04梁桁-02軒桁` のような構造クラス、基礎は
  `04構造-01基礎-…`、スラブや壁の**構成層**は素材ごとのクラス（`z構成要素-コンクリート` /
  `z構成要素-合板` など）に分かれ、層の塗り・ペンは**クラス属性に従います**。断面の
  ハッチングや線をクラス側で変えれば、取り込んだ全部材に反映されます。
- **構造材の端点は接合点（芯線の交点）** … 構造材ツールの芯線は、横架材なら**天端中央**、
  柱なら**断面中心**を通ります。そこで端点を接合相手の芯線上へ置き、材が実際に止まる位置は
  構造材の**端部オフセット**（符号つき）で戻します。**描画される形は同じ**ですが、部材の端点が
  接合点に一致するので、座標から接合関係を取得できます。

  | 端 | 端点 | 端部オフセット |
  | --- | --- | --- |
  | 柱・束の上端 | 受ける横架材の**天端** | −（その梁のせい）。150mm なら `-150` |
  | 横架材の負け側端 | 勝つ材の**天端中央線** | −（勝つ材の半幅）。105mm 直交なら `-52.5` |
  | 横架材が柱に取り付く端 | **柱芯**の軸位置 | −（端点から柱芯までの距離）。柱の手前で止まっていれば負、外周の桁のように柱の外面まで来ていれば正 |
- **シートレイヤ** … 伏図が `1`（基礎伏図）から順に並び、**軸組図はその続きの番号**で
  並びます（伏図が 1〜7 なら軸組図は 8 から）。軸組図が 1 枚の用紙に収まらないときは
  シートレイヤが増え、タイトルが `軸組図(1)` / `軸組図(2)` … と連番になります。
- **縮尺は用紙と建物の大きさから自動で決まります**（1/200・1/175・1/150・1/125・1/100・
  1/75・1/50・1/30・1/25・1/20・1/15・1/10・1/5 のキリの良い値だけを使い、用紙に収まる
  中でいちばん大きい図を選びます）。用紙は**シートレイヤの印刷可能領域**（書類設定の
  用紙サイズから印刷の余白を引いたもの）を読むので、余白の設定がそのまま図の大きさに
  反映されます。**伏図はすべて同じ縮尺・同じ位置**なので、用紙をめくっても建物の位置が
  動きません。グラフィック凡例のぶんは用紙の右に空けてあり、図と重なりません。
  軸組図は**上下 2 段**になる縮尺で整列します。
- **図面枠**（タイトルブロック）は、設定ダイアログで**図面枠スタイル**を選んだときだけ、
  伏図・軸組図の**すべてのシートレイヤ**に 1 つずつ置かれます（ダイアログの初期値は
  [「使い方」](usage.md#2-実行する)）。用紙の中心に合わせて置かれ、ビューポートより背面に
  入ります。軸組図は図面枠の内側へ並べますが、伏図の並べ方は図面枠を考慮しないので、枠と
  重なることがあります（[「既知の制限」](known-limitations.md)）。
- **寸法**は、設定ダイアログで**寸法規格**を選んでいれば（既定で選ばれています。
  [「使い方」](usage.md#2-実行する)）、伏図・軸組図の各ビューポートの**注釈**として
  入ります。押さえるものは図によって違います:

  | 図 | 押さえるもの |
  | --- | --- |
  | 基礎伏図 | アンカーボルトの位置・立上りの切れ目（端部）は立上りに沿って、立上りの通りは外周で |
  | 床伏図・小屋伏図 | 柱（小屋束を含む）・梁の位置（横架材に沿って） |
  | 母屋伏図 | 母屋・登り梁の芯と、登り梁と母屋・棟木・軒桁の芯の交点（材に沿って押さえる） |
  | 軸組図 | 柱・束の位置（1 階の柱は下、1 階と合わない上階の柱と小屋束は上）、GL・床高・軒高とそこからの横架材天端（左）、標準と違う高さの横架材 |

  伏図の外周は、**四辺に外周の材に乗るもの・取り合うものの位置**、**上と右にはその外に
  全長**を置きます。軸組図には GL・各階の FL・軒高を**レベル基準線**として置きます。
  寸法の見え方（文字・矢印・補助線）は選んだ寸法規格に従います。寸法が図の外へ張り出す
  ぶん、縮尺は用紙から寸法の帯を引いて選びます。寸法・データタグ・レベル基準線はクラス
  「寸法」に置かれます。
- **用紙の割り付け**（用紙・印刷可能領域・凡例の幅や図面枠・建物の広がり・選んだ縮尺）は、
  伏図・軸組図それぞれ 1 行ずつ診断ログの「記録」に残ります。図が思ったより小さい
  （大きい）ときは、どの値が影響したのかをそこで確かめられます（完了ダイアログの
  「ログを表示」から読めます）。

高さは**ストーリレベルへのバインド**で持たせてあるので、階高を変えれば部材が追随します。
