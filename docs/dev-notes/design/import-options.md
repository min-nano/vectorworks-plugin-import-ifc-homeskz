# 取り込み設定の決め事（M20）

IFC を選んだ直後に**設定ダイアログ**を 1 枚出し、「どの要素を図面のどのシンボルで置くか」を
決めてもらう（`draw/SettingsDialog`）。レイアウトダイアログ・シンボル表示コントロール・
図面のリソース一覧の SDK 作法は SDK リファレンスの
[レイアウトダイアログ](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Layout%20Dialogs.md)
と [シンボル](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Symbols.md)
にある（この機能で使った呼び出しの具体は `draw/SettingsDialog.cpp` の冒頭コメント）。
このプラグインとしての決め事は次のとおり。

- **設定は「フェーズ間で運ぶ値」**（`core::ImportOptions`）。決めるのは描画側——図面に
  どんなシンボルがあるかは VectorWorks にしか問い合わせられない——で、使うのは解析側（命令へ名前を
  書き込むのは解析）。したがって Document と同じく `core/` に置く。**役割の表（表示名・
  既定名）は `core::symbolRoles()` ただ 1 つ**で、解析側はシンボル名の固定値を持たない。
- **既定は従来の固定名のまま。** 設定を変更しなければ取り込みの結果は変わらない——設定を
  追加したことで既定の振る舞いが変わってはいけない（`ParseImportOptionsTests` が全フィクスチャで
  担保する）。
- **名前ではなくサムネイルで選べることが要点。** 選択は**サムネイル付きのポップアップ**
  （VectorWorks 自身の「鋼材断面を選択」などと同じコントロール）にする。"床束" と "床束2" の
  どちらが必要な図形かは名前からは決まらないためである。表示されるのは VW がリソースに対して
  持っているサムネイルそのもので、こちらで描画モードやビューを決める必要が無い。
- **行は縦に積まず 2 列に折り返す。** 1 行の高さはサムネイルの高さで決まり、**その大きさは
  選べない**（`kStandardSize` と、線種用の細長い `kLineTypeSize` の 2 つだけ。上記
  レイアウトダイアログ）。役割の数ぶんそのまま縦に並べると画面に対して細長くなりすぎるので、
  列の先頭を「前の列の先頭行の右」へ置いて折り返す（`kColumnCount` / `RowTail`）。列の数を
  変えるときに変更するのはこの定数だけで、割り切れない分は最後の列が短くなる。
- **行ごとに「取り込むか」のチェックを持つ。** チェックを外した役割は、解析側がその役割の
  命令を 1 つも作らない（描画側で失敗させて診断に出すのではなく、そもそも指示を出さない）。
  アンカーボルトは座金の有無、伏図記号は柱と小屋束で役割が分かれるので、片方だけ取り込む
  こともできる。置きたいシンボルが図面に無いことは普通にある（テンプレート未適用・その
  要素を使わない案件）。そのとき**名前だけを指定して配置しようとしても必ず失敗する**ので、
  はじめから「取り込まない」と指定できるようにした。
- **候補は図面にある「置けるシンボル」だけ。** **シンボル定義の一覧をそのまま出さず**、
  `GetSymbolDefSubType == 0`（＝普通のシンボル定義）だけを候補にする——VectorWorks 自身が
  プラグインオブジェクトのスタイルとして持つ定義（図面枠・データタグ・図面ラベル・
  グラフィック凡例・木質構造材…）が混ざるため（切り分けの根拠は SDK リファレンスの
  [シンボル](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Symbols.md)）。
  **いまの対応先が図面に無い行は、チェックの外れた状態で開く**。図面にシンボルが 1 つも
  無いなら、その旨をダイアログの先頭に表示する。勝手に別のシンボルへ差し替わらないことが
  ここの要点で、通知なしに違うシンボルが配置されるくらいなら何も配置しない方がよい。
  サムネイルのポップアップは項目が**実在するリソース**なので名前だけの項目を作れないが、
  チェックがあるのでそれで足りる（配置するものが図面に無いなら取り込まない）。
- **設定を出せなくても取り込みは止めない。** ダイアログを組めなかったときは既定の対応で
  そのまま進み、その旨をログへ 1 行残す（結果ダイアログの回避策と同じ考え方）。
- **選んだ対応はログの見出しの次に必ず記録する**（`parse::formatImportOptions`）。
  「シンボルが 1 つも置かれない」という報告の切り分けは、まず対応表を読むところから始まる。
- **選択は VectorWorks を起動している間だけ覚え、図面には書かない。** 名前付きリソースを
  増やさないのと同じ考え方で、取り込みの設定を図面へ書き戻さない。

ここまでは M20 のシンボルの役割の決め事。同じダイアログには、のちに役割の 2 列の下へ
図面枠スタイル（[M28](../milestones/m28-title-block.md)）・寸法規格
（[M31](../milestones/m31-dimensions/README.md)）・垂木の断面（[M37](../milestones/m37-rafter-section.md)）・
伏図のまとめ方（[M36](../milestones/m36-plan-per-beam-level.md)）の行が追加された（項目の一覧は
`core/ImportOptions.h` の冒頭）。図面枠と寸法規格は `core::ImportOptions` の既定（空＝置かない）
とは別に、**ダイアログの初期値が「置く／入れる」**である（それぞれのページ）。
