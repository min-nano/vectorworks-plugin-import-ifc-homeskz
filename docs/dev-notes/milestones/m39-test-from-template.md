# 実機テストは毎周テンプレートから描き、自分の図面は保存せずに閉じる（M39）

**ご要望**: テスト実行では取り消しやレイヤ削除で前の状態へ戻す方法を捨て、常に仮保存した
一時ファイルをテンプレートとして使う。自分で一時保存した・開いたファイルは覚えておき、
ループを再実行するときに前のファイルを保存せずに閉じる。これで、利用者が保存せずに開いて
いるファイルが無い限り、再起動のときに保存を尋ねるダイアログが出ないようにしたい。

**なぜ戻すのをやめたか。** M25〜M38 の 3 段構え（取り消し → 作業ファイルを開き直す →
前の周が作ったレイヤを消す）は、どの段も「戻ったかどうか」を周ごとに疑う必要があった——
取り消しは取り消しスタックの中身に、レイヤ削除は取り込み前から在ったレイヤへ描画した分が
残ることに左右され、報告の「図面の状態:」で毎回確かめていた。そのうえ前の周の図面は
未保存の変更を抱えたまま開いているので、`vw_restart` のたびに保存の確認が出て人の応答を
待っていた。

**どうしたか。**

- 1 周目に、開いている図面を一時ファイルの置き場へ **`.sta` で別名保存**してテンプレートに
  する。以後の周は毎回これを `OpenDocumentPath` で開く——`.sta` を渡すと**中身を複製した
  無題の新規文書**が開く（[Findings「Documents」](https://github.com/min-nano/vectorworks-developer-sdk-reference/blob/main/Findings/Documents.md)）ので、
  テンプレートは周をまたいで汚れない。`.vwx` の作業ファイルでは**そのファイル自体**が開き、
  描画結果を捨てるのに「別名で保存し直してから閉じる」を挟む必要があった。
- 描き上がりは周の終わりに**一時ファイルへ保存**して、記憶（`ownedDocuments`）に追加する。
  未保存の変更が残らないので、再起動で保存の確認が出ない。
- 次の周の頭で、記憶にある図面のうち開いているものを**保存せずに閉じる**。`CloseDocument()`
  は確認を出さずに変更を捨てる（同 Findings。M25 の時点では「未保存だと閉じられない」と
  読んでいたが、戻り値が false なだけで実際には閉じていた）。人が描き上がりへ手を入れて
  いても捨てる——一時ファイルの図面だからで、残したい描画結果は人が別名で保存する。
- 取り消し（`UndoOneStep`）・レイヤ削除（`RemoveCreatedLayers`）・その相手の記憶
  （`lastCreatedLayers` / `lastCreatedSheets`・`DrawCounts::createdLayers` / `createdSheets`）・
  作業ファイル（`workPath`）を削除した。報告の「人が『取り消し』で戻します」の注記も要らなく
  なった。
- MCP の周は**テンプレートが無ければ走らない**（`feedbackRoundKind` が Refuse）。人の居ない
  周に「いま開いている図面」を基準に採らせると、前の周の描き上がりや利用者の図面がその
  まま基準になりうる。M38 までの記憶にはテンプレートが無いので、更新後は 1 周目をメニュー
  から 1 度やり直す。（M40 からは、MCP の `vw_run_test` に `ifc` と `template` を名指しすれば
  人の手を借りずに 1 周目からやり直せる。→ [M40](m40-auto-first-round.md)）

**閉じる相手の安全弁。** 確認なしに変更を捨てる呼び出しなので、CLAUDE.md「開発の基本方針」8
の「消すコード」に数え、`core::isOwnedTestDocument` 1 か所で絞って無 SDK でテストする——記憶に
名指しで在り、記憶のパスが一時ファイルの置き場の中にあること。`SwitchToOpenFile` のあとにも
アクティブな図面を読み戻し、閉じる相手でなければ閉じない。`fFileRef` は記憶に持ち越さない。

**1 周目に元の図面はどうなるか。** 別名保存した文書はテンプレートのファイルそのものに
なるので、そのまま閉じる（保存した直後なので失うものは無い）。元の図面のファイルには何も
書き戻らない——ただし元の図面に未保存の変更があったなら、それはテンプレートにだけ入る
（M25〜M38 の作業ファイルも同じだった）。
