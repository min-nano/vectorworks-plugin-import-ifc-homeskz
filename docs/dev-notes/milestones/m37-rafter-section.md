# 垂木の断面を一律に指定する（M37）

**ご要望**: インポート時に垂木の寸法を指定したい。一律指定でよい。

- **IFC に垂木は出てこない**（parse/Rafter.h 冒頭）ので、断面は M6 から 45×45 の決め打ち
  だった。これを取り込み設定（`core::ImportOptions::rafterWidth` / `rafterHeight`）へ
  出した。**既定は 45×45 のまま**で、設定ダイアログを出さない経路（実機テストの続きの周・
  ダイアログを出せなかったとき）でも従来と同じ描画結果になる。
- **一律＝全垂木・全階で 1 つ。** 屋根面ごと・階ごとには分けない（ご要望）。間隔（@455）は
  寸法ではないので据え置き。
- **断面が反映されるところは 3 つ**で、どれも解析側で閉じる:
  1. 垂木命令の幅・せい（描画はそのまま構造材の断面へ渡すだけ。draw/ は変えていない）。
  2. 両端の垂木を屋根面の端から寄せる量（＝**幅の半分**。`sweepPositions` の inset）。
  3. 野地板の持ち上げ（野地板下端＝垂木上端なので、屋根版の平面から**せい**を鉛直換算して
     加える。`parse/Roof` の `roofCommandForPlane`）。ここを 45 のままにすると、せいを大きく
     したとき垂木が野地板を突き抜ける。
  仕様ラベル（`45×45@455`）も指定値で組む。端数は丸めて消さない（`60.5×90@455`）。
- **入力は文字の欄 2 つ**（幅・せい）。選ぶものではないのでシンボルの行の仕組み
  （チェック・候補・サムネイル）には乗せず、`VWEditTextCtrl` を DDX で受ける（draw/Feedback
  の PR 番号の欄と同じ、既に使っているコントロールだけ。PR 番号の欄は M38 で削除した）。読むのは
  `core::parseRafterSize` で、**全角の数字・小数点も読む**（日本語入力のまま打たれることが
  普通にある）。strtod を使わないのは小数点がロケールに従うため。
- **読めない・範囲外（0 以下・1000mm 超）の値は前回の値のまま取り込み、ログへ 1 行残す。**
  ダイアログを閉じさせない作りにはしていない（そのための SDK の作法を確かめていない）。
  受け付けた値はログの「設定」の欄（`垂木の断面: 60×90 mm`）と各垂木のラベルで分かる。
- **往復の記憶にも書く**（`rafter.width` / `rafter.height`）。書き落とすと続きの周が
  45×45 で描画し、1 周目と違う条件で黙って走る（図面枠で実際に起きたのと同じ形）。
