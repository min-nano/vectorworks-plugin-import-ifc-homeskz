# 実機テストの条件を記憶しない（M43）

**ご要望**: MCP でテストを回せるようになったので、テスト実行時に前回の記憶を残す必要は
無くなったのではないか。2 回目以降もセッションが希望の設定で回せばよい。必要性を検証し、
不要であれば関連コードを削除して単純化する。続けて、**手動で動作確認するなら通常の
取り込みで足りるので、メニュー「実機テストを実行…」自体も不要ではないか**。

**何を記憶していたか（M42 まで）。** `core/FeedbackSession`（`feedback.txt`）に:

| 記憶していたもの | 何のためか | M43 で |
| --- | --- | --- |
| 1 周目の IFC と取り込み設定（`ifc` / `role.*` / `titleblock` / …） | 2 周目以降を名指し無しで走らせる | **やめた**——Claude が毎周 `ifc` / `settings` を渡す |
| テンプレートのパス（`template`）と、その複製 | 続きの周がどの図面から始めるか | **やめた**——Claude が毎周 `template` を渡す |
| 済んだ周回数・前の周のビルドと内訳（`round` / `build` / `tally`） | 報告の見出しと「前の周からの変化」 | **やめた**——前の周の報告はセッションが持っているので、比べるのはセッション |
| 1 周目の「取り込み前に在ったレイヤ」（`baseline*`） | 図面が取り込み前へ戻っていたかの照合 | **やめた**——M39 から毎周テンプレートを開くので戻し忘れは起きない。報告には枚数だけを出す |
| 自分で保存した図面（`owned.doc`） | 次の周の頭で保存せずに閉じる相手 | **残した**（下記） |

**残したもの: 自分で保存した図面の記録。** `CloseDocument()` は確認なしに未保存の変更を
捨てるので、閉じる相手は「名前で記録した自分の図面で、かつ一時ファイルの置き場の中にあるもの」
に限っている（CLAUDE.md「開発の基本方針」8）。記録をやめて「置き場の中にあるもの」だけで
選ぶと、利用者が置き場から開いた図面まで閉じうる——安全弁を緩める方向の変更になるので採らない。
本体は周の間に入れ替わる（`vw_update`）ので、記録はメモリではなくファイルに置いたままにした。

**メニュー「実機テストを実行…」も削除した。** メニューの周が本番の取り込みより多くして
いたのは「テンプレートから開く・前の周の図面を閉じる・報告をファイルに書く」だけで、どれも
Claude が周を重ねるための仕組みである。人が手で確かめるなら本番の取り込みで足り、その
診断ログも `vw_log` で読める。メニューが無くなったので、実機テストにダイアログを出す経路
（IFC・設定・通りを尋ねる・結果ダイアログ）と、いま開いている図面をテンプレートとして採る
仕組み（`CaptureTemplate`）も削除した。殻（`Extensions/ExtTestMenu`・登録・`.vwr` の文字列）と
境界の `vw_payload_run_test` も無くなり、`VW_PAYLOAD_ABI_VERSION` を 8 に上げた（**殻が
変わるので、このビルドを入れたら Vectorworks の再起動が要る**）。ユニバーサル名と UUID は
使い回さない（`docs/development/identifiers.md`）。

**記憶をやめるために足したもの: `vw_run_test` の `settings`。** M42 までは、人がメニューの
1 周目で選んだ設定（シンボル・図面枠・寸法・伏図のまとめ方・外す通り・垂木）を記憶し、MCP の
周がそれを引き継いでいた。記憶をやめるとその経路が無くなるので、MCP の周は図面から組んだ
既定（`draw::presetImportSettings`）に `settings` を上書きするようにした
（`core::applyTestSettings`。書けるのは設定ダイアログで決められるものすべて）。役割は番号では
なく**表示名**で指す（番号は外へ書き出さない）。**読めない項目があれば何も描かずに断る**——
頼んだ条件と違う条件で黙って走った周の報告は、読む側を誤らせる。

**変わったこと。**

- `vw_run_test` は `ifc` と `template` が必須になった（無ければ `InvalidRequest`）。
  `TestRoundOutcome::NotRemembered`・`core::FeedbackRoundKind` は削除した。
- `template` は一時ファイルの置き場へ複製せず、そのまま開く（`.sta` を開くと無題の新規文書が
  開き、ファイルそのものは変わらない）。複製は「ワークツリーが消えたあとの周も開けるように」
  だったが、毎周渡されるので要らない。
- 報告は 1 周ぶんで完結する。見出しの周回数・「前の周からの変化」の節を削除し、「図面の状態:」は
  取り込み前から在ったレイヤの枚数だけを出す（判定しない）。`vw_run_test` の応答から `round` を
  削除した。
- 描画結果の保存先は `round-N.vwx`（周回数を持たないので、置き場の中で空いている番号）。
