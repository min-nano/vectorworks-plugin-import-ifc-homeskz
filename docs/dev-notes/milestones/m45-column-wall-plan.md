# 柱壁伏図を作り、耐力壁をそこへ移す（M45）

**ご要望**: 柱壁伏図を作成する。耐力壁は床伏図には表示せず、柱壁伏図に表示する。

## 何を作るか（`parse/Sheet` の `buildColumnWallSheetCommands`）

- **床伏図と同じ規則で、伏図レベル（横架材の高さ）1 つにつき 1 枚**（ご要望）。スキップ
  フロアで階を複数段で表すなら、その段ごとに 1 枚（`2階柱壁伏図（FL-872）` /
  `2階柱壁伏図（FL-40）`。高さの添え方も床伏図と同じ `planLevelTitleSuffix`）。床伏図 1 枚に
  柱壁伏図 1 枚が対になる。
  - 最上階（小屋組の階）の伏図レベルには作らない。立つのは小屋束で、母屋伏図が伏図記号で
    示す。
  - 柱も耐力壁も無い伏図レベルには作らない（空のビューポートを残さない）。
- 載せるレイヤは **柱・耐力壁・通り芯** だけ。床・伏図記号は載せない。グラフィック凡例は
  床伏図と同じく常に載せる。
  - 柱は、床伏図と同じ切断（通し番号 + 0.25）を span が含む柱レイヤ。対になる床伏図に
    映る柱と同じ。
  - 耐力壁は、その伏図レベルに立つ span レイヤ（`shearWallLayersFrom`）。「n 階の耐力壁は
    n 階の図」という M19 の規約をそのまま引き継ぐ。
- 最初の版は階に 1 枚（階の全伏図レベルの柱の和）だったが、ご指摘で床伏図と同じ単位に
  揃えた（常に同じ規則で作れる）。
- 横架材は載せない（ご要望。薄く重ねることもしない）。

## 並び順: 下の階から積み上げる

ご要望で、柱壁伏図は**対になる床伏図の直後**に並べる（下から順に積み上がっていく）:

```
基礎伏図 → 1階床伏図 → 1階柱壁伏図 → 2階床伏図 → 2階柱壁伏図 → 2階小屋伏図 → 母屋伏図… → 軸組図
```

- スキップフロアなら段ごとに 床伏図 → 柱壁伏図 が対で並ぶ（`2階床伏図（FL-872）` →
  `2階柱壁伏図（FL-872）` → `2階床伏図（FL-40）` → `2階柱壁伏図（FL-40）`）。
- 母屋伏図はこれまでどおり最後にまとめる。
- **番号は並べる `buildSheetCommands` だけが振る**（基礎伏図は 1、その後ろを 2 から並び順）。
  柱梁伏図・母屋伏図・柱壁伏図の各ビルダーは番号を空のまま返す。並べ方で番号が決まるので、
  ビルダーごとに番号を数えると振り方が 2 か所に分かれる。各ビルダーは「どの伏図レベルの図か」
  を添えた内部の列を返し、`buildSheetCommands` が伏図レベルで突き合わせて併合する。
- この変更で、床伏図より後ろの伏図の番号は柱壁伏図の分だけずれる。軸組図の番号は伏図の
  最大の次から振るので、自動で後ろへずれる。

## 床伏図から耐力壁を外す

柱梁伏図（床伏図・小屋伏図）は耐力壁レイヤを載せなくなった。耐力壁レイヤの縮尺は
`draw/Sheet` の `applyPlanLayerScale` が**どの伏図にも映らない耐力壁も含めて**揃えているので、
記号の大きさは変わらない。

## 寸法（`parse/Dimension` の `columnDimensionChains`）

ご要望で、**耐力壁の有無に依らず柱の位置を押さえる**。上に全柱の X、右に全柱の Y の列
（1 段目）、その外に全長（2 段目。列が全長そのものなら重ねない）。

床伏図のように材の通りに沿って押さえる方式（`framingLineChains`）は使わない。柱壁伏図は
横架材を映さず、耐力壁はすべての柱を通らないので、耐力壁を通りの線にすると耐力壁の無い
通りの柱が押さえられない（最初の版はこの方式で、ご指摘を受けて改めた）。
