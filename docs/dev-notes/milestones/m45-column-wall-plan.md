# 柱壁伏図を作り、耐力壁をそこへ移す（M45）

**ご要望**: 柱壁伏図を作成する。耐力壁は床伏図には表示せず、柱壁伏図に表示する。

## 何を作るか（`parse/Sheet` の `buildColumnWallSheetCommands`）

- **最上階を除く階ごとに 1 枚**（`1階柱壁伏図` / `2階柱壁伏図`）。最上階（小屋組の階）に
  立つのは小屋束で、母屋伏図が伏図記号で示すので作らない。
- 載せるレイヤは **その階の柱・その階の耐力壁・通り芯** だけ。横架材・床・伏図記号は
  載せない。グラフィック凡例は床伏図と同じく常に載せる。
  - 柱は、**その階の伏図レベルすべて**について床伏図と同じ切断（通し番号 + 0.25）を
    span が含む柱レイヤの和。スキップフロアで階に伏図レベルが 2 つ以上あっても柱壁伏図は
    階に 1 枚なので、どの高さに立つ柱も載る（通し柱は重複を除く）。
  - 耐力壁は、その階の伏図レベルに立つ span レイヤ（`shearWallLayersFrom`）。「n 階の耐力壁は
    n 階の図」という M19 の規約をそのまま引き継ぐ。
- 柱も耐力壁も無い階には作らない（空のビューポートを残さない）。
- **番号は母屋伏図の続き**（基礎伏図 → 柱梁伏図 → 母屋伏図 → 柱壁伏図 → 軸組図）。既存の
  伏図の番号を動かさないため。軸組図の番号は伏図の最大の次から振るので、自動で後ろへずれる。

## 床伏図から耐力壁を外す

柱梁伏図（床伏図・小屋伏図）は耐力壁レイヤを載せなくなった。耐力壁レイヤの縮尺は
`draw/Sheet` の `applyPlanLayerScale` が**どの伏図にも映らない耐力壁も含めて**揃えているので、
記号の大きさは変わらない。

## 寸法（`parse/Dimension` の `PlanKind::ColumnWall`）

柱壁伏図は横架材を映さないので、床伏図が横架材を通りの線にするところを**映っている耐力壁の
芯（柱芯どうし）**で置き換え、柱をその上と外周で押さえる（`framingLineChains` を共有）。
