# 実機テストの 1 周目を MCP から尋ねずに始める（M40）

**ご要望**: 初回のテスト実行から、自動でテンプレートを使って適切なオプションで取り込みを
始めたい。可能なら Vectorworks が起動していなくても起動して始める。テンプレートは
リポジトリに置いた `.sta` を 1 周目に開いて使えばよい。

**何が詰まっていたか。** M38〜M39 の `vw_run_test` は「1 周目（IFC と設定の選択）は人が
メニューから」で、記憶が無い・記憶が古い（M39 より前でテンプレートが無い）・一時ファイルが
片付けられた——のどれでも人の手を待っていた。人がするべきことを「描画結果を見て一言書く」まで
減らすには、1 周目の 3 つ（何を取り込むか・どの図面へ描画するか・どの設定で）を人に尋ねずに
決められればよい。

**どうしたか。**

- **何を取り込むか** … Claude が `vw_run_test` の `ifc` で名指しする（`tests/fixtures/` の
  どれか）。名指しされた周は**記憶があっても新しい 1 周目**（`FeedbackRoundKind::AutoFirstRound`）
  ——別の IFC で試し直すのにも人の手が要らなくなる。
- **どの図面へ描画するか** … `template` で `.sta` を名指しする。リポジトリの
  `tests/fixtures/Default.sta`（利用者から頂いたテンプレート）がそれで、**一時ファイルの
  置き場へ複製してから**覚える（`InstallTemplate`）。ワークツリーのパスを覚えると、ワーク
  ツリーを消したあとの続きの周が開くものを失うため。複製したものは M39 と同じく毎周
  `OpenDocumentPath` で開くだけで、開いたまま覚えはしない（自分の図面ではない）。
- **どの設定で** … テンプレートから開いた図面にあるもので組む
  （`draw::presetImportSettings` → `core::presetImportOptions`）。中身は**設定ダイアログを
  まだ一度も決めていないときの初期値**と同じ——既定名のシンボルが図面にある役割だけ取り込み、
  図面枠は最初のスタイル、寸法規格は JIS（無ければ最初）、まとめ方・外す通り・垂木は既定。
  その起動中に人がダイアログで選んだ前回の値は使わない（無人の周の条件が、その日に人が
  何を押したかで変わらないように）。寸法規格の選び方は `core::defaultDimensionStandardIndex`
  1 か所に寄せ、ダイアログと同じものを選ぶ。設定は図面を用意した**あと**に組む（どの
  シンボルがあるかは開いた図面で決まる）。
- **Vectorworks が起動していなければ** … Python の MCP サーバが `vw_launch` と同じ道で起動し、
  橋が架かってから同じ要求を出し直す（`call_with_launch`）。起動するのは `vw_run_test` のとき
  だけ——読むだけの道具で起動すると、橋が落ちた理由（パレットが閉じている等）を Claude が
  調べる前に覆い隠す。起動した直後は道具の一覧を取り直してから頼む（一度も繋がったことが
  無いと待ち時間の表が無く、30 分かかりうる 1 周を既定の 30 秒で諦めてしまう）。

**名指しが使えないときは何も変えない。** IFC が無い・テンプレートが `.sta` でない・無い・
複製できない——どれも記憶を書かずに `TestRoundOutcome::InvalidRequest` で理由を返す。`.sta` 以外を
弾くのは、`OpenDocumentPath` に `.vwx` を渡すと**そのファイル自体**が開き、そこへ描画することに
なるため（M39 の読み戻しが「保存済み」を見て中止はするが、先に言うほうが早い）。

**メニューの周は変えていない。** 人が押す「実機テストを実行…」の 1 周目は従来どおり IFC・
設定・軸組図の通りを尋ね、いま開いている図面をテンプレートに採る。リポジトリのテンプレートは
配布物に入らないので、プラグインはその場所を知らない——名指しできるのはリポジトリを開いて
いる Claude だけ。
