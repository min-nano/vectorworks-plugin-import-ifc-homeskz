# 地中梁の可視ソリッドが幅方向にずれる（M10 の続き）

実機で、**断面の鉛直面が −u 側にある地中梁**（8 通り・ち〜り間・り通り。u は「走る向きを
+90 度回した水平方向」）の**可視ソリッドだけ**が幅方向へ 24.59mm（内側へ）ずれていた。
同じ梁の**削り取り（底盤のノッチ）は正しい位置**で、鉛直面が +u 側にある地中梁は可視
ソリッドも正しかった。命令（`core::ModifierCommand`）は全梁で IFC どおりなので描画側の問題。

**手掛かりは SDK の VWFC ソース**（`VWExtrudeObj(const VWPolygon3D&, double)` と
`VWPolygon3D::GetTransformMatrix`）: 3D ポリゴンからの押し出しは、**局所座標系を先頭の
頂点で決める**——原点＝先頭の頂点、U＝先頭の辺、W＝U×(3 点目−先頭)、V＝W×U。
`draw/Footing` の `CreateModifierPrism` は押し出しを軸方向へ伸ばすために頂点の並びを
Newell 法で揃える（反転する）が、**反転されるのはちょうど鉛直面が −u 側の梁**で、反転後の
先頭の辺は −u 向きになり、**局所座標系が上下逆（V＝−Z）**になっていた。ずれた梁と上下逆の
梁は、この IFC でもフィクスチャでも完全に一致する（y=−2400 の短い梁も同じ向き）。
加えて、可視ソリッドだけは**位置を合わせた後に**クラスと「構造用図形」（`ovIsStructural`）を
立てていた（削り取りはどちらも立てない）。

**直し方（2 つ同時に入れた）**:
1. 頂点の始まりを「+u へ向かう下端の辺」へ回し（`core::modifierBasePolygon`。無 SDK テストあり）、**どの向きの梁も U＝+u・V＝+Z・W＝軸方向**
   の同じ座標系で作る（正しく出ていた +u 側の梁と同じ形になる）。この IFC と全フィクスチャの
   394 本（梁・呑み込み後の梁・床付け）で、この座標系になることを机上で確かめた。
2. 実測による位置合わせ（`AlignModifierPrism`）を、**ソリッドへの設定をすべて済ませた後**に
   行う。

**どちらが効いたかは未確定**（SDK 側の「なぜ上下逆だと・構造用図形を立てるとずれるのか」は
実機でしか分からない）。実機で確かめたら、効いたほうを SDK リファレンスの
「Slabs and Extrudes」へ知見として足す。
